タイトルの「探訪記録」で発見数、初発見日時、場所、紹介文、世界地図を閲覧できる。自由飛行と作戦飛行で部材に接近した時点で登録する。登録前は一覧の名称を伏せ、地図に地点を表示しない。

## 地形・描画・保存

- 開発時に既存の地形、基地、線路、河川を測量。スポット固有の支持地形と海岸断面を制約付きTINへ焼き込み、2,048 mタイルの同じ三角形を表示と高度照会に使用する。
- 巨歯輪は歯先半径2,000 m。垂直な輪の中心は地上80 mで、地表より下のポリゴンを切り取る。遠方で詳細地形を読み込む前にも埋没した輪郭が見える。
- 各部材を軸と両端半径で記述し、立体メッシュと簡略接触形状を生成する。遠近で円周の分割数を切り替え、可視範囲内のモデルをWebGLでバッチ描画する。LOD変更・遠距離移動・タイトル復帰で不要なGPUバッファを解放する。
- 緩い海岸には場所によって幅の変わる砂帯、露出した海岸には岩棚と急斜面を生成する。造船渠の狭い水路と中央海沿いの浅い入り江は、海岸線を内陸へ切り込んで形成する。
- 既存のキャンペーンセーブに、発見済みIDと初回のISO日時を追加する。座標・名称・紹介文は台帳から取得する。個別の発見は自由飛行スコアを加算しない。

## 性能と回帰結果

同一Chromium、1000×640、他の検証終了後に同じ視点で各12フレーム予熱し50フレーム描画。左がPR #13マージ時、右が今回。GPU欄はアプリケーションの全WebGLコンテキストで確保したARRAY_BUFFERの合計。初期化はHTMLを読み込ませてタイトルが初期化されるまでの壁時計時間。

| 視点 | FPS | 描画呼び出し / フレーム | GPU頂点バッファ (MiB) |
|---|---:|---:|---:|
| 巨歯輪南方 | 58.9 → 54.6 | 25 → 26 | 0.35 → 0.44 |
| 造船渠の海側 | 53.7 → 48.6 | 22 → 24 | 0.34 → 0.54 |
| 中央大海 | 60.0 → 55.6 | 3 → 3 | 0.30 → 0.30 |

初期化は920 → 760 ms。短時間の単回測定で、フレームレートと初期化時間には実行時のばらつきがある。テクスチャ、フレームバッファ、ドライバーのメモリは上表の集計外。

新規のmysteryテストと、terrain、world-areas、watershed、railway、ocean、smoke、visual、operations、render-cache、landscapeの各テストが成功。24水系、24陸上基地、8空母、77駅を確認。地形タイルを480回読み込み、480回破棄した。10地点を2周してタイトルに戻る試験ではWebGLバッファ数が毎回元の値に戻った。編集元と配布HTMLはバイト単位で一致した。

スマホの検証はChromiumのビューポート・タッチエミュレーション。実機の熱・電池消費、Safari、GPUの総VRAM使用量は未測定。管理ブラウザーがfileスキームへの直接移動を禁止しているため、ファイルのダブルクリックによる起動は未検証。外部リクエストを禁止した状態で、配布HTMLのみを読み込む飛行・保存・再起動テストが成功した。
