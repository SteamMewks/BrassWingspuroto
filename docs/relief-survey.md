## 世界座標と施工順序

既存の海岸線と島を境界に、250 m 間隔の広域標高場を作る。西部は北東寄りの縞状の尾根、紫煙側は南東寄りの山列と既存の屈曲谷、赤銅側は北東寄りの山列と採掘台地を持つ。谷底・平原・海岸低地が山列を隔てる。白嶺峠の断面と赤棚の採掘段は既存の三角形から取り込む。海面は 0 m、地形の最高点は約 580 m。

海への経路は、海岸からの探索で上り返しと基地・産業用地への侵入にコストを課して選ぶ。複数の源流が共有する経路を合流点で分割し、各河道に下流 ID、次数、中心線、幅、流下標高を記録する。河口は経路を実際の海岸線と交差させて決める。橋梁予定高と周辺地形を上限に縦断標高を解き、河床、岸、水面の順に断面を決定する。新しい源流は幅6 mから始まり、最初の約1 kmで広がる。滝では落差を短区間に集中させて崖を作り、下端に広い滝壺と最大約2.3 mの追加洗掘を設けた。水面は支流末端から合流先の色へ、河口の上流 650 m から近海の色へ移行する。

基地は敷地と緩衝帯、駅と鉄道は構内と線路中心線を測量し、切土・盛土を適用する。海岸、河岸、山腹、造成境界を辺として三角形分割する。ゲームには頂点60,325個と三角形111,082枚を収納し、世界座標を5 cm単位で記録する。描画・衝突・樹木の接地は同じ三角形を使う。メッシュは全ミッションで共有する。空母には造成を適用しない。

各三角形の平均標高で集計した大陸別の面積比を示す。島を除き、端数は丸めている。

## 開発用の再測量

通常プレイに必要なファイルは単体HTMLのみ。開発時に海岸線や交通網を編集した場合は、作業ディレクトリを作成し、リポジトリ直下で次の順に再測量する。Pythonの開発用依存は NumPy、SciPy、Shapely 2、Triangle。ブラウザ環境は DEVELOPMENT.md に従う。

```sh
mkdir -p /tmp/brass-survey
CHROMIUM_PATH=/usr/bin/chromium node tools/relief/survey.cjs /tmp/brass-survey
python tools/relief/build.py /tmp/brass-survey
cp 'Brass_Wings_Homeward (5).html' BrassWings-preview.html
CHROMIUM_PATH=/usr/bin/chromium node tests/watershed.cjs
```
