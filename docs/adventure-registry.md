# 群島飛行記の拠点台帳

座標は世界南西端から東・北へ測ったメートル値。町村の座標は専用滑走路の中心を示す。規模は町村の受付サービスと滑走路の仕様を決める。航空基地の規模は別に管理する。

## 冒険と保存

初回は専用本拠地「真鍮の翼工房」から出発する。格納庫、工房、補給所、倉庫、管制設備、専用旗を持つ。停機中に目的地を選び、離陸は専用ボタンで行う。町村の商店で商品を購入し、町・都市で売却できる。本拠地の倉庫に預けた商品は再び取り出せる。輸送依頼の物資は8枠のうち1枠を使用する。遺構調査は天象演算儀の実地観測と依頼主への報告で完了し、浮遊大陸への手掛かりが残る。

冒険キーは `brassWings.adventure.v1`。最後の停機地点、訪問ID、解放ID、所持金、商品・倉庫在庫、進行中の依頼、摩耗・弾倉、撃墜数、天空への手掛かり、発見日時を保存する。所属は固定の初期配置と解放IDから復元する。旧キー `brassWings.worldCampaign.v1` から発見日時と機体の摩耗・弾倉を読み込む。

## 検証

`node scripts/build.js` の実行後、`node tests/build.cjs` で結合を確認する。`CHROMIUM_PATH=/usr/bin/chromium` を指定して `tests/adventure.cjs`、`tests/smoke.cjs`、`tests/operations.cjs`、`tests/visual.cjs` を実行する。地形と探索の回帰検証には `terrain.cjs`、`railway.cjs`、`watershed.cjs`、`ocean.cjs`、`world-areas.cjs`、`mystery.cjs`、`sky-kingdom.cjs`、`cloud-sea.cjs`、`render-cache.cjs` を使用する。
