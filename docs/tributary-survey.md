# 大陸の集水域と追加河川

[変更前の水系図](watersheds-before.png) ｜ [変更後の水系図](watersheds-after.png)

250 m格子の流下先を海岸から逆に探索し、同じ河口に流れるセルの面積・最長流路・源流高度を集計した。既存9水系は集水量の大きい流域を選んだため、西側では2河口が北端の標高0 m地点に近接し、広い南部に川が少なかった。新規候補は既存流域からの距離、集水面積、源流から河口までの長さで評価した。別の方角に海岸があっても、十分な流路や安全な敷地間隔が取れない流域は除いた。

## 河口と流路の測量

## 河川間隔の変化

500 m格子の陸地点から最寄りの河道中心線までの距離。平均と90パーセンタイルを示す。

|大陸|平均（km） 旧 → 新|90%点（km） 旧 → 新|
|---|---:|---:|
|西部|12.0 → 3.6|29.1 → 7.5|
|紫煙|4.6 → 2.5|10.3 → 5.3|
|南部|8.9 → 3.5|20.0 → 7.3|

間隔は河道の測点を使った近似値。既存78河道は座標、幅、流下高、合流先、滝のインデックスまで変更前と一致した。新規水系は全て造成緩衝帯・道路・駅施設を避けている。鉄道との交差は全線を2 m間隔で検査した。
